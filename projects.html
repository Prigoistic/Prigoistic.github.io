engram: Vector memory engine

A vector memory engine written in Rust that works with Redis clients through the RESP protocol. Uses HNSW for similarity search, SIMD distance calculations, and a write-ahead log for recovery.
STACK Rust, libc, ARM NEON, x86 AVX2/FMA
ARCH HNSW index, event loop, search workers, write-ahead log and snapshots
STATUS Open source
GitHub Blog

cheeger: Differentiable image segmentation

A PyTorch library that treats image features as a graph and learns to segment them using spectral methods. Includes custom graph operators and a differentiable eigensolver, with evaluation as a U-Net segmentation head on Cityscapes.
STACK Python, PyTorch, NumPy and SciPy for validation
ARCH Graph Laplacians, differentiable eigensolver, learned spectral response
STATUS Open source
GitHub Write-up

Poolgrad: Autograd and memory management

A CPU-based autograd engine in Rust for studying computation and memory use in neural networks. Combines a dynamic computation graph, matrix multiplication kernels, task scheduling, and a reusable pool for gradient memory.
STACK Rust, Rayon, ARM NEON, x86 AVX2/FMA
ARCH Reverse-mode autograd, kernel scheduler, gradient memory pool
STATUS Open source
GitHub Paper

Ananta: Scientific and symbolic reasoning

An LLM research project for scientific reasoning, mathematics, and formal logic. Combines energy-based objectives with autoregressive generation to study iterative self-correction.
STACK Python, PyTorch, CUDA, LoRA/QLoRA, RLHF
ARCH Energy-based models, autoregressive decoding, self-play
STATUS Open source
GitHub
